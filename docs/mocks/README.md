# v2 API mocks

Shapes for the v2 product model (`docs/api-contract.md`). Companies, investors, amounts and URLs in these
files are **fictional placeholders** for building the UI; only fund names/ids are real.
- `audit_v2.json`: `POST /api/audit` and `GET /api/audit/demo`.
- `profile_v2.json`: `GET /api/funds/{fund_id}/profile`.
- `funds_search_v2.json`: `GET /api/funds/search`.
- `demos_v2.json`: `GET /api/audit/demos`.
- `deal_v2.json`: `GET /api/deals/{company_id}`.
